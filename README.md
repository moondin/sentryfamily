# SentryFamily

A modern, responsive web dashboard for home security monitoring.

## Features

- Real-time system status monitoring
- Camera feed integration
- Recent activity tracking
- Alert management
- Responsive design for all devices

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Mantine UI
- Tabler Icons
- Recharts
